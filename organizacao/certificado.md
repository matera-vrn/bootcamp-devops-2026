# Certificado 🏅

## Como receber o certificado do Instituto Matera

Para receber o certificado de conclusão do Bootcamp DevOps 2026, você deve:

1. **Concluir o projeto prático** desenvolvido ao longo das aulas (repositório no GitHub com o mini-projeto: scripts, Dockerfile, docker compose e pipeline de CI com GitHub Actions).
2. **Publicar um post no LinkedIn** apresentando o seu projeto:
   - Conte o que você aprendeu e mostre o link do seu repositório no GitHub.
   - Marque a **@Matera** e use a hashtag **#BootcampDevOpsMatera**.
3. Preencher o formulário de solicitação do certificado (link divulgado na Aula 10) com o link do seu post.

## Por que o post no LinkedIn?

Porque portfólio só tem valor quando as pessoas o veem! O post é o primeiro passo para transformar o que você construiu no bootcamp em **visibilidade profissional** — e é assim que recrutadores encontram quem está começando na área.

## Dicas para um bom post

- Mostre um print do seu pipeline verde ✅ no GitHub Actions.
- Conte em 2–3 parágrafos: de onde você partiu, o que construiu e o que quer aprender a seguir.
- Peça feedback — a comunidade responde!
